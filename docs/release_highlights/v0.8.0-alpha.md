### 🌟 Welcome to the Belong on the Spectrum Shared Alpha (`v0.8.0-alpha`)

Belong on the Spectrum is a quiet, sensory-calm community sanctuary designed specifically for actually autistic and neurodivergent adults, families, and organizers.

#### 🔑 What's New in This Release:
1. **Shared Cloud Persistence**:
   - Live **Cloud Firestore** and **Firebase Authentication** are now wired up.
   - Community votes on feature requests and private feedback submitted in the app now persist seamlessly across all alpha testers and devices.
2. **Direct Messages (`Msgs` Tab)**:
   - Quiet, unhurried 1-on-1 conversations with gentle pacing.
   - **Calm Batched Digest Toggle**: Choose to batch non-urgent messages into a quiet once-daily digest rather than receiving continuous notifications.
3. **Actually Autistic Events Calendar**:
   - Sensory accommodation badges on every event:
     - 💡 Lighting: Low / Dim / Natural / Fluorescent Warning
     - 🔇 Sound: Quiet / Moderate / Noise-Canceling Recommended
     - 🧘 Sensory Quiet Room availability
     - 🎭 Masking policy: Completely optional, unmasked sanctuary
   - **1-Tap Sensory RSVP**: RSVP with accommodation requests directly in the app.
4. **Calm Notifications Architecture**:
   - Member-first notification controls with zero high-arousal bells or intrusive badge nag counts.
5. **Multi-Platform Availability**:
   - Live Web Progressive Web App (PWA): [https://belongonthespectrum.web.app](https://belongonthespectrum.web.app)
   - Android Release APK delivered directly via Firebase App Distribution to `pre-alpha-testers`.
6. **Multi-Tier Quality Guarantee**:
   - 56 automated unit tests and BDD widget tests passing with 0 errors.
   - Real glass verification on physical Google Pixel 9a.
