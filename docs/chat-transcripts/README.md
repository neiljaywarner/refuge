# Temporary chat learning archive

This is a temporary learning archive, **not product documentation**. It is for apprentices, curious readers, and anyone who later wants to understand how Neil and the RedBot / Grok Bot assistant worked on Belong / Refuge.

- [Start with the chat notes](2026-11-session.md): Neil's available words, times, and the assistant's reported progress.
- [Look at token-analysis notes](2026-11-session-token-analysis.md): rough estimates of how much text was used and ideas for doing similar work more efficiently.
- [Download the estimate table](2026-11-session-token-analysis.csv).
- [Related GitHub issue #880](https://github.com/neiljaywarner/refuge/issues/880) tracks later analysis.

The archive covers October 24–November 8, 2026. Times are Central Time (America/Chicago), with the seasonal clock change handled. Original spelling is kept in available quotes. Sensitive details are replaced. Many source messages were already shortened, so this is **not a verbatim full-text transcript** and cannot recover their missing endings. Assistant status updates are reports, not independently checked evidence that a task finished. Token counts are estimates, not actual billed usage.

For non-technical readers: a GitHub issue is a task note; a pull request proposes a change; merging accepts that change. Accepting a change does not necessarily put it on the live website. CodeRabbit is an automated reviewer. Appwrite and Firebase store or process app information. GetStream supplies video-call tools.
