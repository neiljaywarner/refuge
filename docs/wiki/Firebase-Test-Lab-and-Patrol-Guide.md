## Dev-only safety

Every Test Lab build uses:

- `-t lib/main_dev.dart` (via Patrol `build android` dart-defines)
- `--dart-define=FLAVOR=dev`
- `--dart-define=ENABLE_SERVERPOD=false`
- Package `com.belongonthespectrum.refuge.dev` only (upload refused otherwise)

Do not upload `com.belongonthespectrum.refuge` or prod hosting.

## Patrol native tests (LeanCode)

Install the CLI ([Patrol setup](https://patrol.leancode.co/documentation/native/setup)):

```bash
dart pub global activate patrol_cli
patrol doctor
```

Read-only FTL targets under `integration_test/`:

| File | What it proves |
| --- | --- |
| `patrol_ftl_home_shell_test.dart` | Home branding, tone filters, bottom nav, Vote & Feedback (no taps that post or sign in) |
| `patrol_ftl_bottom_nav_readonly_test.dart` | Bottom nav semantics keys switch Search / Notifications / Home |
| `patrol_ftl_native_resume_test.dart` | Native `pressHome` + `openApp` for the `.dev` package ([native overview](https://patrol.leancode.co/documentation/native/overview)) |
| `patrol_hello_world_test.dart` | Legacy alias of the home-shell smoke |

Local device (not Test Lab):

```bash
patrol test -t integration_test/patrol_ftl_home_shell_test.dart \
  --dart-define=FLAVOR=dev \
  --dart-define=ENABLE_SERVERPOD=false
```

`integration_test/test_bundle.dart` is generated by Patrol; do not commit it.

## Firebase Test Lab pipeline

### Dry run

```bash
dart run tool/run_firebase_test_lab.dart --dry-run
```

Prints `patrol build android …`, badging gate, and `gcloud firebase test android run`.

### Build only (badging gate)

```bash
dart run tool/run_firebase_test_lab.dart --build-only
```

Uses `patrol build android` when the `patrol` CLI is on PATH; otherwise falls back to `flutter build apk` + Gradle.

### Upload

Requires `gcloud auth login` and project `belongonthespectrum`:

```bash
dart run tool/run_firebase_test_lab.dart \
  --target integration_test/patrol_ftl_home_shell_test.dart
```

Default target is `patrol_ftl_home_shell_test.dart`.
