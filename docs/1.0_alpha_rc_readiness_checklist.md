  - **Member Directory Suite** (`test/features/profile/belong_members_directory_view_test.dart`): 2/2 tests passing green with sub-2-second widget execution.
  - **Member Activity Counters Suite** (`test/features/profile/member_profile_activity_counters_test.dart`): 4/4 tests passing green.

### 2.2 Bugs Discovered & Resolved During Audit
1. **Analyzer Serverpod Contamination (Issue #370)**: Excluded nested `sanctuary_server/**` and `serverpod_scaffold/**` from root `analysis_options.yaml`, eliminating 20+ false-positive analyzer errors.
2. **Notification Controller Reactivity**: `BelongNotificationsNotifier` keeps the in-app unread count in sync. It does not update a phone launcher dot. The MethodChannel has no native handler ([#411](https://github.com/neiljaywarner/refuge/issues/411)).
3. **Missing `onBackToSpaces` Parameter (Issue #369)**: Added required navigation callback in `BelongMembersDirectoryView` across member directory and activity counter test harnesses.
4. **Member Directory Assertion Alignment**: Updated test assertions to match curated dev dummy members (`Marty (Organizer)`, `Caleb Stone`, `Sarah Chen`, `David Okafor`) and unified composite text labels (`DFW Church (Partner) • Community Organizer & Founder`).

### 2.3 UX Friction Points & Discoveries
- **Registration Form Church Affiliation Seam**: When registering via `SimpleAuthView` (Firebase UI Auth), the form asks for Email and Password, but the required ICOC church affiliation selection resides inside `MemberProfileDialog` / `BelongAuthSheet`. For 1.0 Alpha RC, new sign-ups should either present a gentle onboarding step or allow church affiliation to be populated peacefully in their profile.
- **Persistent Bottom Nav Labels (Issue #362)**: `SalomonBottomBar` collapses inactive tab text labels to icons only (`Home`, `🔔 3`, `💬`, `🔍`). For autistic members who experience cognitive friction with ambiguous icons, persistent visible labels provide superior predictability.
- **Sensory Font Scale Discoverability**: Font scaling (`100%`, `115%`, `130%`) is currently nested inside the "About Belong" modal. Elevating this to a top-level setting or app bar action will improve accessibility for members experiencing reading fatigue.

## 3. Disciples Today & Church Affiliation Defaults Evaluation

### 3.1 Disciples Today Directory Architecture
Disciples Today (`disciplestoday.org/church-locator`) organizes the global International Churches of Christ (ICOC) network through:
1. **Geographic Search / Locator**: City, State, ZIP code, or Country radius lookup.
2. **Regional Groupings**: Continental groupings (North America, Latin America, Europe, Africa, Asia-Pacific) rather than a rigid top-level list.
3. **Campus & Specialized Ministries**: Dedicated locators for student and family ministries.

### 3.2 Evaluation of Current Belong Options
Currently, `CommunityBrandConfig.belong()` defines:
- `DFW Church (Partner)` (Launch Partner)
- `Austin Christian Church`
- `Boston Church of Christ`
- `Greater Long Beach Church`
- `Other ICOC Congregation`
- `I am not a member of an ICOC church`

### 3.3 Recommendation for 1.0 Alpha RC Soft Launch
- **Launch Partner Prominence**: Keep `DFW Church (Partner)` as the primary featured option.
- **Gentle Free-Text / Autocomplete Field**: Rather than a restrictive 5-item dropdown that forces disciples in other cities (e.g. Chicago, London, Atlanta, San Diego) to select "Other ICOC Congregation", provide an autocomplete or free-form text input with gentle suggestions.
- **Unhurried Optionality / Blank Field**: For neurodivergent seekers, visitors, and allies who may not belong to an ICOC congregation, allow the field to be left blank or defaulted to `"Welcoming Visitor / Friend"` without triggering validation error blockers.
