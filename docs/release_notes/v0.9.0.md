# Belong on the Spectrum v0.9.0

Thank you for testing. This is an early pre-alpha build.

## How to try it
- **Web / PWA:** https://belongonthespectrum.web.app
- **Android:** Firebase App Distribution (`pre-alpha-testers` group)

## Highlights (what you will notice)
- **Timestamps on posts and direct messages** — each message shows when it was sent, beside the content ([#421](https://github.com/neiljaywarner/refuge/pull/423)).
- **Clearer full-screen sheets on Android** — modal sheets (including Vote & Feedback) clear the system navigation bar instead of leaving it dimmed ([#418](https://github.com/neiljaywarner/refuge/pull/422)).
- **Honest feedback flow** — the feedback sheet no longer claims GitHub filing or an external upload URL; notes go to Firestore `member_feedback` with a clipboard handoff ([#416](https://github.com/neiljaywarner/refuge/pull/416)).
- **Announcement copy** — the welcome wiki no longer says the project was worked on for months ([#417](https://github.com/neiljaywarner/refuge/pull/417)).

## Engineering (no UI change)
- Appwrite opt-in client seam ([#412](https://github.com/neiljaywarner/refuge/pull/412)), Kotlin JVM target fix ([#413](https://github.com/neiljaywarner/refuge/pull/413)), added widget test coverage ([#424](https://github.com/neiljaywarner/refuge/pull/424)), GWT-style test readability ([#426](https://github.com/neiljaywarner/refuge/pull/426)).
